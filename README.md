# LocalRAG

A local document Q&A app powered by [Microsoft Foundry Local](https://github.com/microsoft/Foundry-Local). Upload PDF, DOCX, or TXT files and ask questions — answers are generated only from your indexed documents. Everything runs on your machine; no API keys required.

## Features

- Upload and index **PDF**, **DOCX**, and **TXT** documents
- Semantic search with **Qwen3 Embedding 0.6B**
- Answers generated by **Qwen3 4B** running locally
- SQLite-based vector store (no external database)
- Streamlit chat UI (Turkish interface)

## Requirements

| Requirement | Details |
|-------------|---------|
| OS | Windows |
| Python | 3.11 or newer |
| Disk space | ~5–8 GB free (for model cache) |
| RAM | Enough to run a ~4B parameter model locally |
| Internet | Required **once** for first-time model download |

## Quick start

### 1. Clone or download the project

```powershell
cd c:\path\to\LocalRAG
```

### 2. Create and activate a virtual environment

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If activation is blocked:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Verify you're using the venv Python:

```powershell
where python
```

Expected: `...\LocalRAG\.venv\Scripts\python.exe`

### 3. Install dependencies

```powershell
pip install streamlit foundry-local-sdk-winml pypdf python-docx numpy
```

**Important:** If you previously installed the wrong `docx` package, remove it first:

```powershell
pip uninstall docx -y
pip install python-docx
```

Verify the correct package:

```powershell
python -c "import docx; print(docx.__file__)"
```

- Good: `...\site-packages\docx\__init__.py`
- Bad: `...\site-packages\docx.py`

### 4. Test and Run the app

First,

```powershell
streamlit run llm_test.py
```
Then,

From the project root (where `app.py` is located):

```powershell
streamlit run app.py
```

Open the URL shown in the terminal (usually `http://localhost:8501`).

## How to use

1. In the sidebar, select one or more documents (PDF, DOCX, TXT).
2. Click **Belgeleri indekse ekle** to index them.
3. Wait for indexing to finish (document and chunk counts will update).
4. Type a question in the chat box at the bottom.
5. The assistant answers based only on your indexed documents.

A sample document is included at `data/documents/foundry_test.txt` for testing.

## First run: model download

On first use, Foundry Local downloads two models:

| Model | Purpose | Approx. size |
|-------|---------|--------------|
| `qwen3-embedding-0.6b` | Document embeddings | ~hundreds of MB |
| `qwen3-4b` | Chat / answers | ~2.7–2.9 GB |

**This only happens once.** Models are cached locally; later runs are much faster.

Approximate download time for Qwen3-4B:

| Connection | Time |
|------------|------|
| ~10 Mbps | 25–40 min |
| ~50 Mbps | 5–10 min |
| ~100 Mbps | 3–5 min |

The UI may show `Model SDK cache'ine indiriliyor...` with no progress bar — that is normal. Check Task Manager for network/disk activity if it seems stuck.

After download, the model still needs to load into memory (`model.load()`), which can take another 30 seconds to a few minutes.

## Project structure

```
LocalRAG/
├── app.py                 # Main Streamlit app (start here)
├── llm_test.py            # Simple Foundry Local LLM test

├── src/
│   ├── chunker.py         # Text chunking

│   ├── document_loader.py # PDF / DOCX / TXT loading
```

Always run commands from the folder containing `app.py`.

## Troubleshooting

### `ModuleNotFoundError: No module named 'exceptions'`

Wrong `docx` package installed. Fix:

```powershell
pip uninstall docx -y
pip install python-docx
```

### App uses global Python instead of venv

Activate `.venv` before running, and confirm with `where python`.

### `Bu bilgi eklenmiş belgelerde bulunamadı`

The answer wasn't found in indexed documents. Index at least one document first, or ask about content that exists in your files.

### Download seems stuck

First-time model download can take 5–30+ minutes. Confirm network activity in Task Manager. Ensure you have enough free disk space (~5–8 GB).

### Out of memory errors

Close other applications. Qwen3-4B needs several GB of RAM/VRAM to run.

## Privacy

- No API keys or cloud services — all processing is local.
- Uploaded documents are stored in `data/documents/`.
- Text chunks and embeddings are stored in `db/localrag.db`.
- Do not commit personal documents or the database if sharing this repo.
